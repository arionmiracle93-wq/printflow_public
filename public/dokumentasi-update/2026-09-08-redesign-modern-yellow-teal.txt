4. SISTEM DESAIN GLOBAL
----------------------------------------------------------------

Perubahan tidak hanya untuk dashboard. Komponen global ikut berubah:

- .card        : radius modern, border tipis, shadow teal lembut
- .btn-primary : golden yellow (aksi utama)
- .btn-secondary: teal (aksi pendukung kuat)
- .btn-ghost   : border teal (aksi netral)
- .input       : fokus teal dengan ring lembut
- .label       : uppercase kecil dengan letter spacing
- .chip        : font lebih tegas
- selection    : highlight kuning lembut
- scrollbar    : teal lembut

Komponen lama yang masih menggunakan class indigo diberi brand override
ke teal. Ini membuat semua halaman mengikuti warna baru tanpa merusak
warna semantik seperti merah untuk terlambat, oranye untuk risiko, dan
hijau untuk selesai.

9. CARA MENERAPKAN DI VERCEL
----------------------------------------------------------------

1. Upload/commit semua file perubahan ke GitHub.
2. Pastikan package.json dan package-lock.json ikut diupload.
3. Vercel akan build otomatis (biasanya 1-3 menit).
4. Buka alamat aplikasi lalu tekan refresh.
5. Kalau tampilan lama masih muncul, lakukan hard refresh:
   - Windows: Ctrl + Shift + R
   - Mac    : Cmd + Shift + R
   - HP     : tutup tab, buka lagi; jika perlu bersihkan cache Chrome

Tidak perlu:
- Mengubah DATABASE_URL
- Menyentuh Neon
- Menjalankan /api/setup
- Menghapus data
