KESEPAKATAN KE DEPAN (KONVENSI DOKUMENTASI)
================================================================

1) Kalau balasan panjang DAN penting untuk dokumentasi perubahan,
   maka dibuatkan file .txt di folder ini.

2) Nama file: TAHUN-BULAN-TANGGAL-judul-singkat.txt
   Contoh: 2026-09-20-notifikasi-whatsapp.txt

3) Isi file .txt selalu memuat bagian ini:
   - Jawaban singkat / ringkasan
   - Alasan perubahan
   - Apa yang berubah (sebelum vs sesudah bila relevan)
   - Langkah yang WAJIB dilakukan pemilik (misal jalankan /api/setup)
   - Daftar file yang harus diupload ke GitHub
   - Hasil pengujian
   - Dampak ke kuota / biaya bila ada
   - Saran langkah berikutnya

4) File ini (00-DAFTAR-ISI.txt) diupdate setiap ada dokumentasi baru
   supaya selalu menjadi peta terkini.

5) Balasan pendek yang tidak berdampak ke kode tidak perlu
   didokumentasikan, supaya folder ini tetap bersih.
