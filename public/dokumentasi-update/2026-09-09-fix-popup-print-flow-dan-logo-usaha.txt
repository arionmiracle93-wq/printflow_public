2. PERBAIKAN BUG POPUP FOTO BERKEDIP
----------------------------------------------------------------

PENYEBAB:
Job card dashboard mempunyai efek hover yang memakai CSS transform
(card bergerak naik sedikit). Modal popup sebelumnya berada DI DALAM
card tersebut dan memakai posisi fixed.

Dalam browser, elemen fixed yang berada di dalam parent ber-transform
bisa berubah titik acuannya. Saat cursor/popup mengubah keadaan hover,
transform aktif-mati berulang sehingga layar terlihat blink/kedip.

SOLUSI:
Popup sekarang dirender menggunakan React Portal langsung ke
"document.body", bukan sebagai anak dari job card.

Tambahan kestabilan:
- Klik tombol memakai preventDefault + stopPropagation.
- Scroll halaman dikunci selama popup terbuka.
- Tombol Escape menutup zoom terlebih dahulu, lalu popup.
- Klik hanya pada area gelap luar yang menutup popup.
- Popup memakai z-index terpisah (100), zoom foto z-index 110.
- Event mousedown diperiksa agar klik isi modal tidak menutup modal.
- Style popup diperbarui sesuai yellow-teal.

Hasilnya: popup tidak lagi dipengaruhi hover/transform job card.

5. FITUR UPLOAD LOGO USAHA
----------------------------------------------------------------

LOKASI:
    Menu Pengaturan -> card "Logo Usaha"

CARA PAKAI:
1. Buka menu Pengaturan.
2. Cari card "Logo Usaha".
3. Klik "Upload Logo".
4. Pilih file logo.
5. Klik "Muat Ulang Header" atau refresh halaman.
6. Logo langsung menggantikan icon robot di kiri atas.

FORMAT:
- PNG
- JPG / JPEG
- WEBP

BATAS:
- Maksimal 2 MB.
- Saran ukuran 512 x 512 piksel.
- Logo persegi atau logo dengan background transparan memberi hasil
  paling rapi.

KEAMANAN:
- SVG tidak diterima untuk mencegah risiko script aktif di berkas.
- File dibatasi tipe MIME dan ukuran.
- Logo disimpan di database Neon (tabel business_branding).
- Hanya satu logo aktif; upload baru mengganti logo lama.

FALLBACK:
- Jika belum ada logo, icon robot tetap tampil.
- Jika gambar gagal dimuat, icon robot otomatis tampil.
- Tombol "Kembali ke Ikon Robot" menghapus logo usaha.

PENEMPATAN:
- Logo usaha hanya menggantikan icon di header pojok kiri atas,
  tepat di sebelah tulisan "Print Flow".
- Ikon robot pada konteks AI lain (contoh Ringkasan AI) boleh tetap
  tampil karena fungsinya menjelaskan AI, bukan logo usaha.


6. PERUBAHAN DATABASE
----------------------------------------------------------------

Tabel baru:
    business_branding

Kolom:
- id          : selalu 1 (hanya satu logo aktif)
- mime        : jenis file gambar
- size_bytes  : ukuran file
- data        : isi gambar (bytea)
- updated_at  : waktu update

Endpoint baru:
- GET    /api/branding/logo  -> menampilkan logo
- POST   /api/branding/logo  -> upload / ganti logo
- DELETE /api/branding/logo  -> hapus logo
