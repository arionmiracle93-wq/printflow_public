1. ERROR YANG MUNCUL
----------------------------------------------------------------

Vercel berhasil compile, tetapi gagal saat TypeScript check:

    ./src/components/MobileMoreMenu.tsx:34:22
    Type error: Type '"kasir"' is not assignable to type
    '"owner" | "karyawan"'.

Baris yang bermasalah:

    roles: ["owner", "kasir"]


2. PENYEBAB
----------------------------------------------------------------

Role login sudah disederhanakan menjadi:

    owner
    karyawan

Role berikut sudah tidak valid:

    operator
    kasir

File MobileMoreMenu.tsx merupakan file navigasi versi lama. Pada versi
terbaru sebenarnya file tersebut sudah tidak digunakan/dihapus.

Namun, bila update project dilakukan dengan cara upload/drag file baru
ke GitHub, GitHub TIDAK otomatis menghapus file lama yang tidak ikut
di-upload. Akibatnya file lama masih berada di repository dan tetap
diperiksa oleh TypeScript, walaupun tidak di-import aplikasi.

TypeScript memeriksa semua file .ts/.tsx dalam folder src berdasarkan
tsconfig.json. Karena itu file tidak terpakai pun dapat menggagalkan
build jika berisi type error.


3. BARIS KUNING BUKAN ERROR UTAMA
----------------------------------------------------------------

Pesan berikut hanya WARNING:

    npm warn deprecated ...
    npm warn allow-scripts ...

Warning tersebut tidak menyebabkan build gagal.

Bukti pada log:

    Compiled successfully in 11.3s
    Running TypeScript ...
    Failed to type check.

Jadi masalahnya bukan npm, Neon, Vercel, atau database. Masalahnya hanya
file TypeScript lama dengan role "kasir".


4. PERBAIKAN YANG DITERAPKAN
----------------------------------------------------------------

File berikut dibuat ulang sebagai file kompatibilitas:

    src/components/MobileMoreMenu.tsx

Versi baru:
- Hanya menerima role Owner dan Karyawan.
- Tidak memiliki kata role "operator" atau "kasir".

Navigasi mobile utama tetap menggunakan:

Jadi file kompatibilitas ini hanya pengaman deployment lama/manual.
