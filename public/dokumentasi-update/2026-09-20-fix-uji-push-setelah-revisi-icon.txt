1. KEMUNGKINAN PENYEBAB
----------------------------------------------------------------

Perubahan gambar icon sendiri tidak seharusnya mematikan Web Push.
Namun proses berikut dapat mengubah keadaan perangkat:

- APK di-uninstall lalu install ulang.
- Service worker berubah versi.
- VAPID key pernah dibuat/dimasukkan ulang.
- Subscription browser lama tidak cocok dengan public key server.
- Browser masih menganggap subscribed, tetapi row Neon sudah hilang.
- Izin notifikasi Android kembali default/ditolak setelah reinstall.
- Chrome/Android Battery Saver atau Do Not Disturb membatasi notifikasi.

Karena sebelumnya tombol test hanya memberi status umum, sulit
membedakan masalah Android dan masalah server. Sekarang diagnosis
dipisahkan menjadi dua.


2. UJI LOKAL
----------------------------------------------------------------

Tombol:
    Uji Lokal

Tidak menggunakan:
- Vercel push sender
- VAPID
- Neon subscription
- Firebase/Chrome push endpoint internet
- Icon notifikasi dinamis

Uji Lokal langsung memanggil:

    serviceWorkerRegistration.showNotification()

Tujuannya hanya memeriksa:
- Permission Android = granted
- Service worker aktif
- Android/Chrome bersedia menampilkan notifikasi

INTERPRETASI:

A. Uji Lokal MUNCUL
   Android + permission + service worker baik.
   Masalah berada pada subscription/VAPID/pengiriman server.
   Lanjut ke Perbaiki Subscription lalu Uji Push Server.

B. Uji Lokal TIDAK MUNCUL
   Masalah bukan Neon/VAPID. Periksa:
   - Android Settings -> Apps -> Print Flow -> Notifications -> Allow
   - Jika tidak ada Print Flow, cek Chrome -> Notifications -> Allow
   - Matikan sementara Do Not Disturb
   - Matikan sementara Battery Saver
   - Pastikan permission pada card tertulis granted
   - Tekan Periksa Ulang
   - Update Chrome Android

Uji Lokal sengaja tidak memakai icon agar kegagalan icon tidak dapat
mengganggu diagnosis permission.


3. UJI PUSH SERVER
----------------------------------------------------------------

Tombol:
    Uji Push Server

Menguji seluruh jalur:

    Print Flow API (Vercel)
        -> VAPID
        -> subscription Neon
        -> Chrome/FCM push service
        -> service worker Android
        -> notification panel

Sekarang test hanya menargetkan perangkat akun yang sedang login +
Owner, bukan semua user tanpa batas.

Response menampilkan:
- attempted
- sent
- failed
- removed
- errors statusCode/message/deviceName

INTERPRETASI:

attempted = 0
    Tidak ada subscription database untuk akun. Perbaiki Subscription.

sent > 0
    Push service menerima pesan. Jika panel tidak muncul, cek Android,
    Do Not Disturb, permission, dan service worker.

failed > 0
    Response sekarang menampilkan detail error.

status 404 / 410
    Subscription kedaluwarsa; row otomatis dihapus. Aktifkan ulang.

Error p256dh/auth/key
    Subscription rusak/tidak cocok; Perbaiki Subscription.


4. TOMBOL PERBAIKI SUBSCRIPTION
----------------------------------------------------------------

Tombol:
    Perbaiki Subscription

Yang dilakukan:
1. Unsubscribe subscription browser lama.
2. Hapus seluruh subscription Neon milik akun login.
3. Minta service worker melakukan update.
4. Refresh status card.

Setelah selesai:
1. Tekan Aktifkan Notifikasi.
2. Tekan Izinkan bila Android bertanya.
3. Tekan Uji Lokal.
4. Tekan Uji Push Server.

Jika public key server berbeda dari applicationServerKey subscription
lama, tombol Aktifkan juga otomatis mengganti subscription.

7. STATUS VAPID VERCEL
----------------------------------------------------------------

Buka:
    https://printflow-orcin.vercel.app/api/apk/check

Harus:
    vapidConfigured: true
    serviceWorkerReady: true
    infrastructureReady: true

Environment:
- NEXT_PUBLIC_VAPID_PUBLIC_KEY = Config
- VAPID_PRIVATE_KEY = Secret
- VAPID_SUBJECT = Config (mailto:email)

Public/private key harus berasal dari satu pasangan yang sama.
Jangan membuat private key baru tanpa memperbarui public key pasangannya.
