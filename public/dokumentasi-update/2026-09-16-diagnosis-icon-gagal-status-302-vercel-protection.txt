2. ARTI STATUS 302
----------------------------------------------------------------

302 bukan "file tidak ada".
302 berarti request dialihkan ke URL lain.

Dalam kondisi ini request anonim kemungkinan dialihkan oleh Vercel
Deployment Protection / Vercel Authentication.

Kenapa icon bisa dibuka manual?
- Browser Anda sudah login ke akun Vercel.
- Browser mempunyai cookie otorisasi Vercel.
- Saat membuka URL manual, Vercel mengenali Anda dan menampilkan icon.

Kenapa Chrome Manifest/PWABuilder gagal?
- Validator/crawler meminta icon tanpa cookie Vercel.
- Vercel mengalihkannya ke halaman login/authentication.
- Response bukan PNG, tetapi redirect/text.
- Validator menyimpulkan "icon failed to load".

Mengapa /api/pwa/check juga 302?
- Endpoint check sengaja melakukan request anonim server-to-server.
- Ini meniru PWABuilder/Android OS yang tidak mempunyai cookie Vercel.
- Jadi hasil false justru mengungkap protection yang sebenarnya.


3. URL YANG DIPAKAI ADALAH DEPLOYMENT/PREVIEW URL
----------------------------------------------------------------

Screenshot memakai URL dengan akhiran acak seperti:

    printflow-plt5evgll-arionmiracle93-1104.vercel.app

Ini tampak seperti generated deployment URL, bukan Production Domain
utama yang stabil.

Menurut dokumentasi resmi Vercel:
- Standard Protection melindungi Preview dan Deployment URLs.
- Production Domain terkini pada Hobby biasanya tetap publik.
- Protection bekerja sebelum routing/proxy aplikasi.

Artinya kode Print Flow tidak dapat membypass protection tersebut.
Pengaturannya harus dilakukan di dashboard Vercel.

Referensi resmi:
https://vercel.com/docs/deployment-protection
https://vercel.com/docs/deployment-protection/methods-to-bypass-deployment-protection


4. SOLUSI YANG HARUS DILAKUKAN DI VERCEL
----------------------------------------------------------------

A. TEMUKAN PRODUCTION DOMAIN

1. Buka Vercel Dashboard.
2. Pilih project Print Flow.
3. Buka Settings -> Domains.
4. Cari domain yang diberi label Production / Primary.
5. Copy domain tersebut.

Biasanya bentuknya lebih stabil, contoh:

    https://print-flow.vercel.app

atau custom domain milik Anda.

Jangan gunakan deployment URL dengan hash/akhiran acak untuk
PWABuilder.

B. CEK DEPLOYMENT PROTECTION

1. Vercel -> Project -> Settings.
2. Buka Deployment Protection.
3. Pastikan Production Domain tidak dilindungi Vercel Authentication
   atau Password Protection.
4. Preview deployment boleh tetap dilindungi.
5. Simpan perubahan bila ada.

CATATAN KEAMANAN:
Print Flow sudah mempunyai login Owner/Karyawan sendiri. Membuat
Production Domain publik pada level Vercel tidak berarti Dashboard
terbuka bebas; proxy Print Flow tetap mengarahkan pengguna ke /login.

Yang perlu publik:
- Halaman login
- Manifest
- Icon
- Service worker
- Halaman lacak pelanggan

Halaman internal tetap dilindungi login Print Flow.

- Lebih mudah dikenali validator karena berakhiran .png.
- Menghindari domain deployment lama tersimpan dalam manifest cache.
