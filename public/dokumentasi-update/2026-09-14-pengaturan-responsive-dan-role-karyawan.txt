2. AKAR OVERFLOW HALAMAN PENGATURAN
----------------------------------------------------------------

Ditemukan beberapa penyebab yang saling menambah:

- Host DATABASE_URL panjang dan dipaksa berada satu baris dengan label.
- Baris kondisi sistem memakai max-width + truncate, tetapi parent flex
  tetap dapat mempertahankan lebar minimum konten.
- Kelompok tombol menggunakan flex-wrap, namun beberapa label tombol
  panjang masih mempunyai intrinsic width besar.
- Beberapa card/grid/flex belum memakai min-width: 0.
- URL, status notifikasi, dan keterangan panjang belum semuanya dapat
  memecah kata panjang.
- Proteksi overflow baru ada pada body, belum khusus subtree Pengaturan.


3. PERBAIKAN RESPONSIVE PENGATURAN
----------------------------------------------------------------

A. CONTAINER HALAMAN

Ditambahkan class:
    settings-page

Dengan aturan:
- min-width: 0
- max-width: 100%
- overflow-x: clip

B. SEMUA CARD / GRID / FLEX DI PENGATURAN

Pada mobile dipaksa:
- min-width: 0 !important
- max-width: 100% !important

Ini mencegah anak flex/grid memaksa parent melebar.

C. TEKS PANJANG

Untuk p, span, link, button, dan code:
- overflow-wrap: anywhere
- word-break: break-word

Host Neon yang sangat panjang sekarang turun baris, bukan memperlebar
layar.

D. KONDISI SISTEM

Sebelum:
- Label dan nilai selalu sejajar kiri-kanan.
- Nilai panjang memakai truncate.

Sekarang mobile:
- Label berada di baris pertama.
- Nilai berada di bawahnya.
- Nilai dapat wrap/break-all.

Tablet/desktop:
- Kembali sejajar kiri-kanan.
- Nilai maksimal 65% lebar dan rata kanan.

E. TOMBOL

Pada mobile tombol dibuat satu kolom/full width untuk:
- Upload/ganti/hapus logo
- Aktifkan/uji/nonaktifkan notifikasi
- Data contoh/reset
- Diagnosis/tes kecepatan/catatan/JSON
- Konfirmasi zona berbahaya
- Manajemen user

Pada layar sm ke atas, tombol kembali auto-width/flex.

F. CARD KHUSUS

LogoSettings, PushNotificationSettings, AdminActions, Kondisi Sistem,
APK/PWA, dan User Management mendapat:
- min-w-0
- max-w-full
- overflow hidden/clip yang aman
- heading break-words

G. GLOBAL SAFETY

html dan body memakai overflow-x: clip.
body dibatasi max-width: 100vw.

Tujuannya sebagai pagar terakhir; konten tetap dibuat wrap sehingga
informasi tidak sekadar tersembunyi.

5. ISTILAH OPERATOR TETAP ADA PADA PEKERJAAN
----------------------------------------------------------------

Yang digabung adalah ROLE LOGIN, bukan istilah tugas produksi.

Istilah berikut tetap dipakai:
- Operator mesin
- PIC pekerjaan
- Dari operator / kepada operator pada serah-terima shift
- Nama operator pada job card

Contoh:
- Role login: Karyawan
- Tugas pekerjaan: Operator/PIC = Pak Andi

Satu Karyawan dapat bertugas sebagai operator, kasir, finishing, atau
CS sesuai kondisi lapangan.


6. MIGRASI AKUN LAMA OTOMATIS
----------------------------------------------------------------

Saat /api/setup dijalankan:

    role = operator  -> karyawan
    role = kasir     -> karyawan

Data akun TIDAK dihapus:
- Nama tetap
- Username tetap
- Password hash tetap
- Riwayat tetap
- Status aktif tetap

`token_version` dinaikkan satu kali untuk akun lama yang dimigrasikan.
Akibatnya akun lama otomatis logout dan harus login kembali. Ini
sengaja agar cookie lama dengan role operator/kasir tidak terus dipakai.

Perintah migrasi bersifat idempoten:
- Setup pertama: role berubah, token version naik.
- Setup berikutnya: tidak berubah lagi dan token tidak naik lagi.

Hasil uji:
    legacyop:operator:1 -> legacyop:karyawan:2
    legacycash:kasir:1  -> legacycash:karyawan:2
    setup kedua         -> tetap version 2

10. LANGKAH DEPLOY (WAJIB DIPERHATIKAN)
----------------------------------------------------------------

1. Push seluruh perubahan ke GitHub.
2. Tunggu Vercel Ready.
3. Buka sekali:

       https://alamat-aplikasi.vercel.app/api/setup

   Jika memakai SETUP_TOKEN:

       https://alamat-aplikasi.vercel.app/api/setup?token=TOKEN_ANDA

4. Pastikan response ok:true.
5. Semua akun Operator/Kasir lama akan menjadi Karyawan.
6. Minta semua user login ulang.
7. Di HP, tutup PWA/Chrome lalu buka kembali.

Tidak perlu membuat ulang akun dan tidak perlu reset password.
