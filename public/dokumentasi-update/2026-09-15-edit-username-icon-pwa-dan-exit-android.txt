1. EDIT USERNAME
----------------------------------------------------------------

SEBELUM:
Halaman Kelola Pengguna hanya menyediakan:
- Ganti role
- Reset password
- Aktif/nonaktif akun

SEKARANG:
Ditambahkan tombol:
    Ubah Username

LOKASI:
1. Login sebagai Owner.
2. Klik badge user.
3. Pilih Kelola Pengguna.
4. Cari akun yang ingin diubah.
5. Klik Ubah Username.
6. Masukkan username baru.
7. Konfirmasi perubahan.

ATURAN USERNAME:
- Minimal 3 karakter.
- Maksimal 30 karakter.
- Huruf kecil.
- Boleh angka.
- Boleh titik (.)
- Boleh underscore (_)
- Boleh minus (-)
- Tidak boleh spasi.

Contoh valid:
    andi
    rina.operator
    kasir_utama
    staff-malam

Contoh tidak valid:
    a
    Pak Andi
    @operator

UNIK:
Username tidak boleh sama dengan pengguna lain.
Jika sudah dipakai, aplikasi memberi pesan:
    "Username sudah dipakai pengguna lain."

SESSION:
Setelah username berubah, session lama user dibatalkan.
User harus login ulang menggunakan:
- Username baru
- Password lama (password tidak berubah)

Jika Owner mengubah username akun dirinya sendiri:
- Muncul pemberitahuan.
- Otomatis dialihkan ke halaman Login.
- Login memakai username baru.

ALASAN KEAMANAN:
Cookie session lama masih memuat username lama. tokenVersion dinaikkan
agar session lama tidak terus digunakan setelah identitas berubah.

HASIL UJI:
- stafflama -> staffbaru: BERHASIL
- Login stafflama: DITOLAK 401
- Login staffbaru: BERHASIL 200
- Username tidak valid: DITOLAK 400
- Username duplikat: DITOLAK 409
- Ubah username Owner sendiri: session dicabut -> /login

4. APAKAH LOGO USAHA OTOMATIS MENJADI ICON PWA?
----------------------------------------------------------------

Tidak otomatis.

Upload Logo Usaha di Pengaturan mengganti logo di HEADER Print Flow.
Icon PWA/APK menggunakan file static:
- icon-192.png
- icon-512.png
- icon-maskable-512.png

Saat ini icon PWA memakai identitas robot Print Flow yellow-teal yang
sudah disiapkan.

Alasan dipisah:
- Browser menyimpan icon instalasi sangat agresif.
- Manifest membutuhkan file ukuran tertentu yang dapat diakses publik.
- Logo header dari database bisa berubah kapan saja.
- Icon APK/PWA sebaiknya stabil agar tidak berubah-ubah di HP user.

Jika Anda ingin logo usaha menjadi icon APK/PWA, file icon tersebut
dapat diganti secara manual dengan logo usaha yang sudah dibuat dalam
ukuran 192/512/maskable sebelum generate APK.


5. CARA MEMERIKSA PWA SEBELUM KONVERSI APK
----------------------------------------------------------------

Setelah deploy:

1. Buka di Chrome desktop.
2. Tekan F12 -> Application.
3. Buka Manifest.
4. Pastikan icon 192, 512, dan maskable terlihat tanpa error.
5. Buka Service Workers.
6. Pastikan /sw.js Activated and running.
7. Coba Install App / Add to Home Screen.

Di Android:
1. Buka URL Print Flow di Chrome.
2. Menu tiga titik Chrome.
3. Pilih Install app / Tambahkan ke layar utama.
4. Pastikan icon Print Flow tampil.
5. Buka: seharusnya tanpa address bar browser (standalone).

Jika address bar Chrome masih terlihat seperti screenshot browser,
itu berarti sedang membuka versi mobile web, bukan PWA standalone.


6. PERILAKU BACK & EXIT DI ANDROID
----------------------------------------------------------------

A. MOBILE WEB DI CHROME

Tombol Back Android:
- Kembali ke halaman web sebelumnya.
- Tekan berulang sampai riwayat habis.
- Setelah habis, kembali ke tab/halaman sebelumnya atau menutup konteks
  Chrome sesuai perilaku browser.

Address bar dan toolbar Chrome tetap terlihat.

B. PWA YANG DI-INSTALL

PWA berjalan dalam mode standalone tanpa toolbar Chrome.

Tombol Back Android:
- Jika ada riwayat navigasi Print Flow: kembali satu halaman.
- Jika berada di halaman awal/root dan tidak ada riwayat: Android akan
  keluar/minimize dari jendela PWA dan kembali ke layar/app sebelumnya.
- Tombol Home selalu memindahkan aplikasi ke background.
- Recent Apps dapat digunakan untuk menutup/swipe aplikasi.

Secara penggunaan, perilakunya mirip aplikasi Android normal.

C. APK PWA/TWA DARI PWABUILDER

Trusted Web Activity menggunakan Activity Android yang menampilkan
Print Flow fullscreen.

Tombol Back:
- Menelusuri history halaman web di dalam TWA.
- Ketika history habis/root, Activity ditutup/minimize dan kembali ke
  layar sebelumnya/home (tergantung cara aplikasi dibuka).

D. APK WEBVIEW SEDERHANA

Perilaku bergantung pembuat wrapper:
- Wrapper yang baik: WebView back jika bisa; Activity finish jika root.
- Wrapper buruk: Back bisa langsung menutup atau tidak bekerja.

Karena itu gunakan PWABuilder/TWA, bukan generator WebView sembarang.


7. APAKAH PERLU TOMBOL EXIT DI PRINT FLOW?
----------------------------------------------------------------

Tidak direkomendasikan.

Alasan:
- Aplikasi Android modern biasanya tidak memiliki tombol Exit.
- Pengguna memakai Back/Home/Recent Apps.
- JavaScript web tidak diizinkan menutup window yang tidak dibuka oleh
  script sendiri (`window.close()` biasanya ditolak browser).
- Tombol Exit palsu dapat membingungkan dan tidak konsisten antara
  mobile web, PWA, dan TWA.

Gunakan:
- "Keluar" pada badge user untuk LOGOUT akun.
- Tombol Back Android untuk kembali/menutup Activity.
- Tombol Home untuk background.
- Recent Apps swipe untuk menutup aplikasi.

Penting:
"Keluar" di menu user = logout session, bukan menutup aplikasi.


8. SKENARIO KHUSUS NOTIFIKASI
----------------------------------------------------------------

Jika aplikasi dibuka dari push notification:
- Notifikasi membuka URL pekerjaan tertentu.

Ini perilaku normal Android.
