1. MASALAH DARI GAMBAR
----------------------------------------------------------------

Menu "Lainnya" versi sebelumnya muncul sebagai bottom sheet dari bawah.
Pada Chrome Android, browser juga mempunyai toolbar alamat/navigation
di bagian bawah layar. Kombinasi keduanya membuat:

- Panel terlihat terpotong.
- Bagian menu tampak tertinggal di atas halaman.
- Konten Panduan terlihat berada di tengah kondisi panel.
- Navigasi terasa tidak seperti dropdown desktop.

Permintaan baru:
- Badge user berada di kiri atas.
- Titik tiga berada di kanan atas.
- Titik tiga membuka dropdown ke bawah seperti desktop.
- Menu utama berada di bawah layar.

Semua permintaan tersebut sudah diterapkan.

3. DROPDOWN TITIK TIGA MOBILE
----------------------------------------------------------------

Saat titik tiga kanan atas ditekan, dropdown muncul KE BAWAH dari
tombol tersebut, sama seperti versi desktop.

Isi Owner:
- Produksi Mitra (khusus mobile karena tidak muat di bar bawah)
- Pengaturan
- Catatan Perubahan
- Status Sistem
- Panduan

Pelanggan tidak perlu diduplikasi karena sudah ada di menu bawah.

Perilaku dropdown:
- Rata kanan terhadap tombol.
- Lebar maksimal mengikuti viewport mobile.
- Tinggi maksimal mengikuti tinggi layar (`100dvh`).
- Jika konten lebih tinggi, bagian dropdown yang scroll, bukan halaman.
- Klik di luar menutup dropdown.
- Touch di luar menutup dropdown.
- Escape menutup dropdown.
- Klik menu menutup dropdown.
- Navigasi diprefetch saat disentuh/disorot.


4. NAMA USER PADA MOBILE
----------------------------------------------------------------

Sebelumnya badge user mobile hanya menampilkan inisial.

Sekarang badge mobile menampilkan:
- Inisial
- Nama user
- Role
- Chevron dropdown akun

Lebar maksimum badge menyesuaikan ruang tersisa sebelum tombol titik
tiga. Nama tidak memakai `truncate`.

RESPONSIVE:
- Mobile: nama + role tampil.
- Tablet: hanya inisial agar menu tablet tetap muat.
- Desktop lebar: nama + role tampil penuh.

Nama lengkap juga selalu dapat dibaca di dropdown akun.

8. CARA DEPLOY & REFRESH MOBILE
----------------------------------------------------------------

1. Push semua perubahan ke GitHub.
2. Tunggu Vercel berstatus Ready.
3. Karena service worker/PWA dapat menyimpan shell lama:
   - Tutup semua tab Print Flow.
   - Tutup aplikasi PWA dari recent apps.
   - Buka kembali.
4. Jika tampilan lama masih muncul:
   Chrome -> Site Settings -> Storage -> Clear site data,
   lalu login kembali.
5. Jika memakai PWA yang di-install dan tetap lama:
   - Hapus shortcut/aplikasi PWA.
   - Buka URL di Chrome.
   - Install kembali ke layar utama.

Data pekerjaan tetap aman di Neon. Clear site data hanya menghapus
cache/session browser dan mengharuskan login ulang.
