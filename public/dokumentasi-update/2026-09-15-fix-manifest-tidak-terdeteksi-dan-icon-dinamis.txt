2. KENAPA ICON TIDAK ADA DI FOLDER PUBLIC GITHUB?
----------------------------------------------------------------

Dalam project platform AI saat ini, folder public sebenarnya berisi:

    public/icon-192.png
    public/icon-512.png
    public/icon-maskable-512.png
    public/apple-touch-icon.png

Dimensi sudah diverifikasi:
- icon-192.png          = 192 x 192
- icon-512.png          = 512 x 512
- icon-maskable-512.png = 512 x 512
- apple-touch-icon.png  = 180 x 180

Jika file tersebut tidak terlihat di GitHub Anda, berarti file binary
PNG belum ikut di-upload dari platform AI ke repository GitHub.

Upload source manual tidak selalu membawa file hasil generate dari
platform, terutama jika hanya memilih folder src atau file kode yang
berubah.

----------------------------------------------------------------

- Aksen kuning/teal

File PNG di public tetap dipertahankan sebagai fallback, tetapi
manifest utama tidak lagi bergantung kepadanya.


4. MANIFEST DINAMIS
----------------------------------------------------------------

Manifest utama sekarang dilayani dari:

    /api/pwa/manifest

Layout halaman menyisipkan:

    <link rel="manifest" href="/api/pwa/manifest">

Manifest dapat diakses tanpa login dan menggunakan content type:

    application/manifest+json

Field utama:
- id: /
- name: Print Flow — Monitoring Produksi Percetakan
- short_name: Print Flow
- description
- lang: id-ID
- dir: ltr
- start_url: /
- scope: /
- display: standalone
- display_override: standalone, minimal-ui
- orientation: portrait-primary
- background_color
- theme_color
- categories: business, productivity, utilities
- icons 192/512/maskable
- shortcuts Pekerjaan Baru/Daftar Pekerjaan
- launch_handler: navigate-existing
- prefer_related_applications: false

Icon memakai URL absolut sesuai domain deployment saat ini, sehingga
PWABuilder tidak salah mencari domain.

8. LANGKAH SETELAH DEPLOY
----------------------------------------------------------------

1. Push/upload file kode di bagian 7.
2. Tunggu Vercel deployment berstatus Ready.
3. Buka URL berikut satu per satu:

    https://domain-anda/api/pwa/manifest
    https://domain-anda/api/pwa/icon/192
    https://domain-anda/api/pwa/icon/512
    https://domain-anda/sw.js
    https://domain-anda/api/pwa/check

4. Semua harus HTTP 200.
5. `/api/pwa/check` harus menampilkan ok:true.
6. Tutup semua tab DevTools.
7. Buka domain utama di tab baru.
8. DevTools -> Application -> Manifest.
9. Jika masih "No manifest detected":
   - Klik kanan Reload -> Empty Cache and Hard Reload.
   - Application -> Service Workers -> Update.
   - Application -> Storage -> Clear site data.
   - Tutup dan buka browser lagi.


9. PWABUILDER
----------------------------------------------------------------

Setelah `/api/pwa/check` ok:true:

1. Buka https://www.pwabuilder.com
2. Masukkan DOMAIN UTAMA Print Flow, bukan URL deployment lama.
3. Pastikan domain sama dengan domain yang baru saja diuji.
4. Jalankan Start/Scan ulang.
5. Jika hasil lama masih muncul, gunakan tombol re-scan/refresh dan
   tunggu beberapa menit karena PWABuilder dapat menyimpan hasil scan.

Jangan memasukkan:
- URL /login
- URL /api/pwa/manifest
- URL preview deployment lama

Masukkan contoh:
    https://printflow-domain-anda.vercel.app

12. CATATAN SCREENSHOT PWABUILDER
----------------------------------------------------------------

Peringatan "Add screenshots to showcase your app" bersifat opsional
untuk pengalaman listing/instalasi yang lebih kaya. Bukan syarat dasar
agar PWA dapat di-install.

Peringatan `related_applications`, `file_handlers`, `protocol_handlers`,
`widgets`, dan fitur eksperimental lain juga bukan error wajib.

Yang wajib diprioritaskan:
- Manifest terdeteksi
- Service worker aktif
- HTTPS
- Icon 192 dan 512 valid
- start_url/scope/display benar

Semua komponen wajib tersebut sekarang sudah tersedia secara dinamis.
