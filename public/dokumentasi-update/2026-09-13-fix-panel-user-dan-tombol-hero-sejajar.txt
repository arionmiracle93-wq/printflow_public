1. MASALAH PANEL USER
----------------------------------------------------------------

Pada screenshot mobile, setelah badge user ditekan, panel akun terbuka
namun bagian kirinya keluar layar / terpotong.

Penyebab:
- Badge user berada di sisi kiri header mobile.
- Dropdown masih menggunakan posisi `right: 0`.
- Panel selebar 240px membuka ke arah kiri dari ujung kanan badge.
- Karena badge berada dekat kiri layar, sebagian panel keluar viewport.


2. PERBAIKAN PANEL USER
----------------------------------------------------------------

Posisi dibuat responsive:

MOBILE:
    left: 0
    right: auto
    top: 3rem

TABLET / DESKTOP:
    left: auto
    right: 0
    top: 2.75rem

Lebar panel sekarang:

    min(16rem, 100vw - 2rem)

Artinya:
- Maksimal 256px.
- Selalu menyisakan minimal 16px pada kedua sisi layar.
- Tidak dapat melewati batas viewport.
- Nama panjang tetap dapat dibungkus (`break-words`).

Panel mobile sekarang membuka dari sisi kiri badge menuju kanan, bukan
melebar keluar ke sisi kiri layar.


3. TOMBOL DASHBOARD SEJAJAR
----------------------------------------------------------------

Tombol:
- Pekerjaan Baru
- Semua Pekerjaan

Sebelumnya menggunakan flex-wrap. Jika total lebar tombol melebihi
ruang, tombol kedua turun ke baris berikutnya.

Sekarang pada mobile menggunakan:

    display: grid
    grid-template-columns: repeat(2, minmax(0, 1fr))
    width: 100%
    gap: 0.5rem

Hasil:
- Kedua tombol selalu berdampingan.
- Lebarnya sama.
- Tidak ada tombol yang turun ke baris kedua.
- Teks memakai ukuran 11px pada mobile agar tetap muat.
- Padding mobile dibuat lebih ringkas.
- Ikon tidak mengecil (`shrink-0`).
- Teks tidak pindah baris (`whitespace-nowrap`).

Pada layar `sm` ke atas, tombol kembali menggunakan flex dengan ukuran
teks dan padding normal.
